# Chapter 2. Financial data structures, item by item

This chapter is the first with arithmetic in it, so the v2 items are mostly formulas and algorithms rather than
principles. Every bar definition is broken into its own claims: what closes a bar, what the running statistic is, what
the expectation it is compared against is estimated from, and what carries across the boundary. The four information
driven families each get one item per line of their derivation, so the tick rule, the imbalance, the expectation of the
imbalance, the threshold and the frequency argument are separate rows that separate tests can falsify. The ETF trick,
PCA hedge weights and the futures roll are walked formula by formula and each one is marked not applicable with the
reason that a 300-second binary token is already a single cash-like claim that never rolls. The bar package is inside
the confirmation's registered code, so where the project's default deviates from the book the literal rule is available
and tested while changing the default is deferred to the analysis on 2026-10-24.
