# Chapter 1. Financial machine learning as a distinct subject, item by item

Chapter 1 carries no formula. What it carries is a set of claims about how research must be organised, and each of
them can be turned into something a machine checks: who owns which step, what a station must guarantee before the next
one may use its output, which stage of a strategy's life a result belongs to, and which ten pitfalls the rest of the
book exists to remove. This file breaks the chapter's twenty-four headings into those individual claims. Where the
claim is about people - fifty PhDs in silos, a team of specialists, a National Laboratory - it is marked not applicable
with the reason, because this project is one developer and a plan graph. Where it is about evidence - count the trials,
judge on data no selection saw, let capital follow written rules - it is implemented and a named test can fail if the
rule were broken. The registered-code freeze of the 2026-09-18 confirmation is recorded here as a constraint item,
since it decides what any later item in chapters 2-5 is allowed to change.
