# Chapter 3. Labeling, item by item

Chapter 3 replaces the label that nearly every finance paper uses with one that respects the path a price took. The v2
items pull that apart into its pieces: the fixed-horizon formula and each of the three reasons the book gives for
abandoning it, the volatility estimate that makes a barrier width a function of risk, the three barriers and all eight
of their on-off configurations with the book's own verdict on each, the first-touch search, the binning rule for side
labels and for meta-labels, and the four arguments the book gives for meta-labelling being worth the extra model. Each
configuration and each formula is its own row, so a test that checks one of them cannot accidentally be taken as
evidence for another. The labels this project actually uses are settlement labels - a bet is one token held to a
settlement at zero or one - so several items record how the book's construction maps onto a vertical barrier that is
the contract's own expiry, and the one item that would need a change to the frozen `src/pmlab/labels.py` is deferred.
