# Chapter 14. Backtest statistics, claim by claim

v2 of `docs/afml_sections/ch14.md`: every statistic the chapter asks a backtest report to carry, every formula behind
one, every data structure and algorithm, and every warning, as its own item, each implemented and evaluated, deferred,
or not applicable with a reason. Book text paraphrased throughout.

Here a bet is a token bought inside a 5-minute window and held to settlement, so leverage is 1, the holding period is
set by the entry second, and a maker's returns are left-skewed lottery shapes that normal approximations misjudge.
`pmlab.afml.backtest_stats` holds the chapter's four snippets and its capacity formula, and
`pmlab.afml.backtest_pipeline.path_statistics` computes one row of these statistics per CPCV path.
