# Chapter 4. Sample weights, item by item

Chapter 4 is the one that makes financial labels honest about depending on each other, and it does it with arithmetic
that can be checked line by line. The v2 items therefore separate every definition from every algorithm built on it:
the concurrency count, the per-unit uniqueness, the average uniqueness and its reading as the reciprocal of a harmonic
mean, the bootstrap limits that explain why overlapping draws oversample, the sequential draw probabilities and the
worked three-label example the book prints, the Monte Carlo that measures the gain, the return-attribution weight, the
piecewise time-decay line with both of its boundary conditions, and the class weights and the library bug the section
warns about. Where the book states a limit or an identity, the test checks the closed form rather than the code path,
so the item can fail if the formula were misread. Uniqueness is extreme in this market - every label runs from its
event to its window's settlement, so labels inside a window overlap heavily - and the items record the measured values
rather than the book's.
