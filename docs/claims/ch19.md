# Chapter 19. Microstructural features, claim by claim

v2 of docs/afml_sections/ch19.md: every logic step, formula, data structure, algorithm, warning and hard constraint of
the chapter's twenty-one headings as its own item. The book's text is a private reference; statements paraphrase it.

What the evaluation looks like here: each estimator is checked against its own closed form or against a simulation
whose true value is set before it runs -- a Kyle equilibrium with a known lambda, a Roll process with a known half
spread and noise variance, a three-Poisson mixture with a known probability of informed trading, a Brownian bar with a
known volatility -- and, where Polymarket's tape gives the truth, against the truth (`research/microstructure.md`).
Two of v1's medium findings close here: the VPIN gate's warm-up veto is fixed and tested, and the minute-open ratio's
wrong baseline is now pinned by a test that derives what it actually measures.

Freeze. Confirmation v2 started 2026-09-19 and the registered code is frozen until the analysis on 2026-10-24. That
covers `src/pmlab/micro.py` and `src/pmlab/afml/microstructure.py`, which hold most of this chapter's estimators, so an
item that would need a change there is deferred with that date. `src/pmlab/afml/micro_features.py`, `tests/**` and the
research scripts are outside the freeze, which is where this node's new work landed.
