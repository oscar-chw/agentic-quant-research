# Chapter 13. Backtesting on synthetic data, claim by claim

v2 of `docs/afml_sections/ch13.md`: every logic step, formula, data structure, algorithm, warning and hard constraint
of each numbered heading as its own item, each implemented and evaluated, deferred, or not applicable with a reason.
Book text paraphrased throughout (a private reference; never copied here).

The chapter fits a discrete Ornstein-Uhlenbeck process to the observed series, simulates many paths from it, and reads
the Sharpe ratio of every profit-taking / stop-loss pair on a mesh, so the exit rule is chosen from the process rather
than from one historical path. `pmlab.afml.synthetic` is that mesh. Tokens here settle at 0 or 1 and are held to
settlement, so no live strategy has an exit corridor; the method was used once, on the gap between the market's logit
price and the fair price (`research/afml_extensions.md`, section 6).
