# Chapter 20. Multiprocessing and vectorization, item by item

v1 (docs/afml_sections/ch20.md) gave one row per heading. This file breaks each heading into its individual claims:
every logic step, formula, data structure, algorithm, warning and hard constraint, each implemented and evaluated, or
recorded as not applicable with the number from docs/hardware.md that decides it.

The chapter's engine is hardware-agnostic by design, so most of it is implementable here: `src/pmlab/afml/parallel.py`
holds the linear and two-nested-loops partitions, the molecule dispatch (`mp_pandas_obj`), the serial debugging path,
asynchronous calls with progress, and on-the-fly output reduction, with `tests/test_afml_parallel.py` checking the
partitions balance and every parallel result equalling the single-process one. What does not carry over is scale: the
book writes for 24 processors and mentions clusters of 5,000; docs/hardware.md gives 12 cores of which research runs may
use 4, so every row that talks about cluster scale says so with that number. The project's own CPU-heavy builds already
follow the chapter: `scripts/afml_events.py` runs per-day molecules in a spawn pool of 4 workers at about 0.8 GB each,
and `scripts/feature_importance.py` turned 5.5 hours of wall clock into 21.8 CPU-hours the same way, with BLAS pinned to
one thread per worker so the pool is not oversubscribed.
