# Chapter 18. Entropy features, claim by claim

v2 of docs/afml_sections/ch18.md: every logic step, formula, data structure, algorithm, warning and hard constraint of
the chapter's fifteen headings as its own item. The book's text is a private reference; statements paraphrase it.

What the evaluation looks like here: every estimator is checked against a source whose entropy is known before it runs
(a fair coin, a Bernoulli(0.1), a uniform alphabet, a Normal), against the book's own worked message values, and by the
measured bias at the message lengths the project actually uses. The chapter's closed forms that had no code -- the
Gaussian entropy and its implied volatility, mutual information and its Normal form, the generalised mean and the
effective number, Meucci's concentration -- are now in `pmlab.afml.entropy` and each is evaluated against a value that
was known in advance.
