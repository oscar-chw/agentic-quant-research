# Chapter 5, second reading (plan/book-v2.md node 15)

Every line of all twelve heading spans re-read against `docs/claims/ch05.md`, and every test a `done` item names
opened. Sixteen new items were added and eighteen rows re-cited or re-statused. The chapter's central claim -
stationarity bought at almost no cost in memory - had no test: one item's note asserted a correlation check at d = 1
that did not exist in the named test, and four other items rested on it. Three of the book's own cases were unreachable
from the one series the fracdiff tests use, so 'already stationary gives d* = 0' and 'an explosive series needs d* > 1'
were carried by a test of the opposite case and by a chapter-17 statistic that returns no differencing order at all.
