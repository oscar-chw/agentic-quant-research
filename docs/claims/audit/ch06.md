plan/book-v2.md node 16. A reader who did not write docs/claims/ch06.md re-read every line of each heading's span in
the book (a private reference, not in this repository: paraphrase only), listed the claims the span
makes, checked that an item carries each one, and opened every test a `done` item names to ask whether it would fail if
the claim were violated. A test that only runs the code, asserts a type or checks something adjacent counts as a
mismatch, however green it is.

Counting: a claim is a distinct assertion -- a logic step, a formula, a data structure, an algorithm step, a warning or
a hard constraint. A heading's topic sentence that the next subsection states and quantifies is counted where it is
quantified, not twice. `items` counts the rows naming that heading after the fixes below.
