# Chapter 18, second reading

An auditor who did not write `docs/claims/ch18.md` re-read every line of all fifteen heading spans, listed the claims,
compared them with the items, and opened every test a `done` item names to ask whether it would fail if the claim it is
attached to were false (plan/book-v2.md node 18).

How to read the counts. **claims** is the distinct assertions of the span as this reading grouped them, at the same
granularity the items use: where one item faithfully carries two sentences of a single assertion they count once, and
where the file carries an item the book does not ask for (a pitfall this project found), items exceed claims.
**missing** names what no item covered before this reading; **test mismatches** names a `done` item whose test could not
have failed if its claim were violated. Both are empty only where the reading found nothing.

What the reading found, in one line each: seven claims of the chapter had no item (Kolmogorov's redundancy-complexity
link, Snippet 18.3's algorithm, the information binary coding discards, the unequal widths of quantile codes, the
martingale half of market efficiency, Fiedor's use of the estimator, and the tick classification the VPIN derivation
stands on); five `done` items rested on tests that did not test them; and two items were deferred behind a portfolio
that the formula never needed. All fourteen are closed here, with tests that can fail.
