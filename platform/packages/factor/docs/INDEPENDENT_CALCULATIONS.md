# Arithmetic and temporal falsification cases

1. **Tied ranks.** For `[1,1,2,3]`, average ranks are `[1.5,1.5,3,4]`. For labels `[1,2,2,3]`, ranks are `[1,2.5,2.5,4]`. Centering at 2.5 gives dot product 15/4 and squared norms 9/2 each, so Spearman IC is `(15/4)/(9/2) = 5/6`. Constant vectors and fewer than two available pairs abstain.
2. **Positions and full costs.** Signals `[1,2,3]` imply weights `[-0.5,0,0.5]`. With initial marks all 100, shares are `[-0.005,0,0.005]`. Exits 110 and 90 on the held assets give gross `−0.005*10 + 0.005*(−10) = −0.1` per unit initial gross notional. Entry notional is 1; exit notional is `0.005*110 + 0.005*90 = 1`. At 10 bps, cost is 0.002 and net is −0.102. No compounding or executable-profit interpretation applies.
3. **Price-adjusted exit cost.** The same two weights with returns +20% and +40% give gross +0.1, turnover `1 + 0.5*1.2 + 0.5*1.4 = 2.3`; at 25 bps, net is `0.1−2.3*0.0025 = 0.09425`.
4. **Future marks cannot select weights.** Remove a future exit price for a held asset: prior weights stay `[-0.5,0,0.5]`; the result is unavailable, not a survivor-renormalized portfolio. Split aggregate scores are suppressed.
5. **Time isolation.** A feature at t consumes return ending at t−1. Changing every test-period price leaves features through the first test decision, all train/validation output and validation selection byte-equivalent. Future labels remain within their own split. Late rows are withheld until their recorded availability time without backfilling earlier decisions.

These calculations are implemented as focused tests. The separate exhaustive checker additionally recomputes every feature, daily IC, weight and cash-flow-derived portfolio statistic in both installed examples and both measured workload sizes. It imports no package calculation code; numerical tolerance is absolute 1e−11 or relative 1e−10. This is an independently implemented arithmetic oracle run by the same task, not an independent human review.

The first complete suite exposed a **fixture-design failure**: alternating every day makes returns ending at t−1 and t+1 share a sign, producing positive IC under the strict lag. A single causal fixture revision uses two-up/two-down returns. The numerical evaluator and negative-test acceptance were unchanged. The final synthetic test result is retained as negative; this is not a repaired historical trading strategy.

Version 0.2.0 additionally compares imported ordinary CSV to a separately specified [manual panel](../examples/price-import/manual-panel.csv) and [manual configuration](../examples/price-import/manual-config.json). The normalized panel bytes and configuration values agree, and the same numerical oracle applies. Provenance differs intentionally: imported trials retain raw CSV/mapping bytes and explicitly label clock assumptions.
